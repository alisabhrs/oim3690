## Predict Before You Delete

### 1. Event Listener

**Line:**
`checkbox.addEventListener('change', () => toggleTask(task.id));`

- **Prediction:** If I remove this line, clicking the checkbox will no longer mark tasks as completed.
- **Actual Result:** The checkbox no longer updates the task's completed status.
- **Was I right?** Yes. The event listener connects the checkbox to the function that updates the task.

### 3. Saving Tasks

**Line:**
`saveTasks();` inside the `addTask()` function.

- **Prediction:** If I remove this line, I can still add tasks, but they will disappear after refreshing the page.
- **Actual Result:** New tasks appear initially but disappear after refreshing because they were not saved.
- **Was I right?** Yes. The `saveTasks()` function saves tasks in localStorage so they remain after refreshing.
