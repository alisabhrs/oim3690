# Week 4

## What I worked on
- This week we started learning how to approach a real website project from the planning stage instead of immediately starting with HTML and CSS
- We worked on planning a screen, creating a new branch, and writing a `PROPOSAL.md`
- I also started thinking about what questions I would need to ask a client before building their website

## What gave me trouble
- The GitHub workflow is still something I have to think through, especially branches and making sure I am working in the correct repository
- I also wasn't completely sure at first what information should go into a proposal before actually starting the website

## Something new I learned
- I learned that a website project should start with understanding the problem and the user, then planning the screens and writing the plan down before focusing on design or code
- I also learned about using files like `PROPOSAL.md` and `AGENTS.md` to give both myself and an AI agent more context about the project

## Working with AI
- One thing that stood out to me was the idea that different AI tools might only see part of a project, while I am the person who has the whole picture
- I realized that AI is more useful when I give it context and clear requirements instead of asking it to make all of the decisions for me
